# SS Herbal India - E-commerce Website

A modern, fully-responsive Ayurvedic nutrition e-commerce website built with React.js.

## 🌿 Features

- ✅ Smooth scrolling with Locomotive Scroll
- ✅ Auto-rotating hero banner with 5 slides
- ✅ Product catalog with filtering & sorting
- ✅ Product detail pages with image gallery
- ✅ Shopping cart with persistent storage
- ✅ Wishlist functionality
- ✅ Product reviews & ratings
- ✅ Upsell & related products
- ✅ Detailed product information tabs
- ✅ Certifications display (GMP, ISO, FSSAI)
- ✅ Responsive design for all devices
- ✅ SEO optimized structure

## 📦 Tech Stack

- **React 18** - UI library
- **React Router DOM** - Navigation
- **Zustand** - State management
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Swiper** - Carousels
- **React Icons** - Icons
- **React Toastify** - Notifications
- **Vite** - Build tool

## 🚀 Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```
